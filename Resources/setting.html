I don't know how to use

Just open this app, and a small icon will appear in the menubar / taskbar / desktop panel, then you can push your media files from a local DLNA client to your computer.

How to use third-party player plugin

  1. Download the plugin you want from xfangfang/Macast-plugins
  2. Open the Macast, and click Open Config Directory in the setting menu
  3. put [some plugin].py in renderer directory
  4. Restart Macast and choose the plugins you want

if you can't find any plugin you want, check here to learn how to write a plugin yourself.

How to debug

Run Macast from terminal

  1. python3 Macast.py


How to build Macast

Macast is written in Python3, so you need to install Python3 first.

  1. Clone the repository
    git clone --depth=1 https://github.com/xfangfang/Macast.git
  2. Run Macast
    python3 Macast.py
  3. Install dependencies
    pip3 install -r requirements/common.txt
  4. Build Macast
    python3 setup.py build

We welcome contributions from the community. Please feel free to submit issues, feature requests, or pull requests.

  1. Fork the repository

  4. Test your changes

How to report a bug

Please report bugs using the issue tracker. When reporting a bug, please include:

  1. Your operating system and version
  2. Macast version
  3. Steps to reproduce the bug
  4. Expected behavior
  5. Actual behavior
  6. Screenshots if applicable
